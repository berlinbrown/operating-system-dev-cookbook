# Operating System Development Notes

This repository is set up as a simple notes workspace for operating system development.

There is **no starter project code** here on purpose — just a place to collect ideas, references, experiments, and learning notes.

## Suggested Notes Structure

Use this as a flexible guide (create folders/files as needed):

- `notes/01-foundations.md`
- `notes/02-boot-process.md`
- `notes/03-memory-management.md`
- `notes/04-processes-and-scheduling.md`
- `notes/05-filesystems.md`
- `notes/06-device-drivers.md`
- `notes/07-networking.md`
- `notes/08-debugging-and-tooling.md`

## Optional Workflow

1. Create a new note file for each topic/session.
2. Track links to specs/books/blogs you use.
3. Capture experiments and outcomes right away.
4. Add a short “next steps” list at the end of each note.
